## 이번 주의 목표

7주차까지 모든 도메인의 개념과 손 감각을 익혔다면, 8주차는 **실전 시뮬레이션과 자가 진단**에 집중하는 주다. 새로운 기술을 배우는 주가 아니라, 지금까지 쌓은 실력이 실제 시험 조건(시간 압박, 온라인 프록터 환경, 낯선 문제)에서도 발휘되는지 검증하고 빈틈을 메우는 주간이다.

> "8주차는 공부가 아니라 리허설이다. 모르는 걸 새로 배우기보다, 아는 걸 시간 안에 꺼내 쓰는 연습을 한다."

---

## Killer.sh 모의고사란 무엇인가

**Killer.sh**는 CKA/CKAD/CKS 시험을 주관하는 Linux Foundation과 제휴한 서드파티 플랫폼으로, 실제 시험과 매우 유사한 환경에서 풀어보는 모의고사를 제공한다.

### 핵심 특징

| 항목 | 내용 |
|---|---|
| 제공 방식 | CKA 시험 등록(구매) 시 **무료로 자동 포함** |
| 제공 횟수 | **2회 세션** (별도 결제 없음) |
| 세션당 접근 기간 | 세션 시작 후 **36시간** 동안 문제 풀이 환경 접근 가능 |
| 문제 풀이 시간 | 실제 시험과 동일하게 **2시간** 타이머 |
| 문제 수 | 실제 시험과 유사한 수의 시나리오 기반 문제 |
| 난이도 | **실제 시험보다 약간 더 어렵게** 출제되는 경향 |
| 환경 유사도 | 웹 터미널 UI, 문제 네비게이션, flag(마킹) 기능 등 실제 시험 UI와 매우 유사 |
| 해설 제공 | 세션 종료 후 **모범 답안(정답 스크립트) 열람 가능** |

### 왜 "약간 더 어렵게" 나오는가

Killer.sh는 의도적으로 실제 시험보다 난도를 높여 출제한다. 이는 "Killer.sh를 통과할 정도의 실력이면 실제 시험은 상대적으로 수월하게 느껴지도록" 설계된 것이다. 따라서 Killer.sh에서 낮은 점수를 받았다고 좌절할 필요는 없다. 중요한 것은 점수 자체가 아니라 **어떤 유형에서, 왜 막혔는지**를 파악하는 것이다.

## 모의고사 활용 전략 — 언제, 어떻게 풀어야 하는가

Killer.sh 세션은 시험 등록 시점부터 사용 가능하지만, 무작정 빨리 쓰는 것은 비효율적이다. **7주차(통합 실습 & 속도 훈련)를 마친 직후**부터 사용을 시작하는 것을 권장한다.

```
[1주~6주]              [7주차]                [8주차]
개념 학습          통합 실습/속도 훈련      Killer.sh 1회차 (실전 시뮬레이션)
+ 도메인별 실습     타이머 걸고 문제 풀이          |
                                            오답 분석 + 취약 도메인 재복습
                                                  |
                                          Killer.sh 2회차 (검증)
                                                  |
                                            최종 점검 + 시험 응시
```

### 1회차 — 실전 시뮬레이션

- **목적**: 지금 실력을 있는 그대로 측정한다.
- **방법**: 실제 시험처럼 2시간 타이머를 걸고, 자료 검색도 시험에서 허용되는 범위(kubernetes.io 공식 문서)로 제한한 채 **혼자** 풀이한다.
- **원칙**: 막힌 문제는 답을 찾으려고 오래 붙잡지 말고 표시(flag)만 해두고 다음 문제로 넘어간다. 실제 시험 전략과 동일하게 훈련하는 것이 목적이다.
- 이 단계에서는 점수보다 **어떤 도메인에서 시간을 많이 썼는지, 어떤 유형이 낯설었는지** 기록하는 것이 더 중요하다.

### 2회차 — 취약점 검증

- 1회차 이후 오답을 도메인별로 분석하고, 취약한 도메인을 복습한 **다음에** 진행한다.
- 목적은 새로운 문제를 푸는 것이 아니라, **약점이 실제로 보완되었는지 확인**하는 것이다.
- 2회차에서도 특정 도메인이 계속 발목을 잡는다면, 해당 주차 노트를 다시 처음부터 훑고 실습을 반복해야 한다.

> **주의**: 두 세션 모두 시작하면 36시간 카운트다운이 시작되므로, 세션을 시작하기 전에 충분한 시간(최소 반나절 이상 비는 날)을 확보해두고 시작할 것.

## 오답 분석 방법론

Killer.sh(또는 자체 모의고사)를 푼 뒤 가장 중요한 작업은 **틀린 문제를 도메인별로 분류**하는 것이다. 점수 자체보다 "어느 도메인에서 반복적으로 틀리는가"가 남은 시간의 학습 방향을 결정한다.

### 분류 기준 — 시험 5대 도메인

| 도메인 | 비중 | 오답 시 재복습 대상 |
|---|---|---|
| Cluster Architecture, Installation & Configuration | 25% | [CKA 02 - Cluster Architecture & Installation (개념)](../02주차-Cluster-Architecture-Installation/CKA-02-Cluster-Architecture-Installation-개념.md) |
| Workloads & Scheduling | 15% | [CKA 03 - Workloads & Scheduling (개념)](../03주차-Workloads-Scheduling/CKA-03-Workloads-Scheduling-개념.md) |
| Services & Networking | 20% | [CKA 04 - Services & Networking (개념)](../04주차-Services-Networking/CKA-04-Services-Networking-개념.md) |
| Storage | 10% | [CKA 05 - Storage (개념)](../05주차-Storage/CKA-05-Storage-개념.md) |
| Troubleshooting | 30% | [CKA 06 - Troubleshooting (개념)](../06주차-Troubleshooting/CKA-06-Troubleshooting-개념.md) |

예를 들어 Storage 도메인 문제(PV/PVC/StorageClass 관련)를 틀렸다면, 단순히 정답 명령어만 외우고 넘어가지 말고 **5주차 개념 노트로 돌아가 PV의 바인딩 원리, StorageClass의 동적 프로비저닝 흐름을 다시 이해**해야 한다. 같은 유형의 다른 문제가 나와도 응용할 수 있어야 진짜 복습이다.

### 오답 원인의 세 가지 유형

오답을 분류할 때는 도메인뿐 아니라 **틀린 이유의 성격**도 함께 기록하면 재발을 막을 수 있다.

| 원인 유형 | 설명 | 대응 방법 |
|---|---|---|
| 개념 부족 | 해당 리소스/필드의 동작 원리를 몰랐음 | 개념 노트 재학습 |
| 명령어 미숙 | 개념은 알지만 imperative 명령/YAML 문법이 손에 안 익음 | 반복 타이핑 드릴 |
| 시간 부족 | 알고 있었지만 시간 내에 못 풀었음 | 스피드 훈련, 단축 명령/alias 활용 |
| 문제 오독 | namespace, 리소스 이름 등 조건을 놓침 | 문제 읽는 습관 교정 (밑줄/체크 습관) |

## 시험 당일 체크리스트 개념

CKA는 PSI Secure Browser를 통한 **온라인 프록터(감독) 시험**이다. 기술 실력과 무관하게 환경 문제로 시험이 중단되거나 부정행위로 오인되는 상황을 막기 위해 사전에 규정을 숙지해야 한다.

### 1. 신분증 준비

- 정부 발급 사진 신분증(여권 등 영문 이름이 기재된 신분증) 1종 필요
- 응시자 등록 시 입력한 영문 이름과 신분증상 이름이 **정확히 일치**해야 함

### 2. 응시 공간 규정

- **책상 위**: 모니터, 키보드, 마우스 외에는 아무것도 놓을 수 없음 (필기구, 물병, 이면지 등 모두 금지)
- **방 스캔(Room Scan)**: 시험 시작 전 웹캠으로 책상 아래, 벽, 천장 등 응시 공간 전체를 촬영해 보여줘야 함
- 방문 닫힌 **독립된 공간**이어야 하며, 타인의 출입/소음이 없어야 함
- 이중 모니터, 스마트워치, 이어폰/헤드셋 등은 원칙적으로 금지 (예외 규정은 시험 안내 메일 확인)

### 3. 온라인 프록터 시스템 사전 점검

- 시험 전 반드시 **System Check**를 진행해 카메라/마이크/네트워크 상태를 점검할 것
- 웹캠은 응시자의 얼굴과 손, 책상 주변이 잘 보이는 각도로 고정
- 네트워크는 **유선 연결 권장** — 무선은 끊김/속도 저하 위험
- PSI Secure Browser 설치 및 사전 실행 테스트 필수

### 4. 시험 언어 설정

- 시험 문제 자체의 기본 언어는 **영어**
- 특정 언어(한국어 포함)에 대해 문제 옆에 참고용 번역을 함께 보여주는 **번역 지원 기능**이 제공되는 경우가 있으므로, 등록 시 설정을 확인해둘 것
- 번역은 어디까지나 보조 수단이며, 정확한 의미 파악은 원문(영어) 기준으로 하는 습관을 들이는 것이 안전하다

## 합격 기준 개념

- CKA는 **정해진 커트라인(합격 점수) 이상**을 획득해야 합격 처리된다. 정확한 수치는 시험 버전에 따라 공지되므로 응시 전 공식 안내를 반드시 확인할 것 (통상 66% 내외로 알려져 있다).
- 시험 결과는 응시 완료 후 일정 기간 내에 이메일로 통보된다.
- **재응시 정책**: 시험 등록 시 일반적으로 **1회의 무료 재응시 기회**가 포함되어 있으며, 유효 기간 내에 사용해야 한다. 재응시 정책과 유효기간은 등록 시점의 공식 정책을 기준으로 하므로 변경 여부를 확인해야 한다.
- 불합격 시에도 좌절하지 말고, 이번 8주차에서 만든 **오답 분석표**를 그대로 활용해 재응시를 준비하면 된다.

## 흔한 실수

- **실수 1**: "Killer.sh는 그냥 문제 풀이 연습용이니 아무 때나 풀어도 된다"
  - 정정: 세션은 시작하는 순간부터 36시간 카운트다운이 시작된다. 충분한 시간을 확보하지 않고 시작하면 해설을 다 보기도 전에 접근이 끊길 수 있다.

- **실수 2**: "Killer.sh 점수가 낮으면 시험에 떨어진다는 뜻이다"
  - 정정: Killer.sh는 의도적으로 실제 시험보다 어렵게 출제된다. 점수 자체보다 **어떤 도메인에서 반복적으로 틀렸는지**가 중요한 신호다.

- **실수 3**: "오답 문제의 정답 명령어만 외우면 복습이 끝난다"
  - 정정: 명령어 암기는 임시방편이다. 왜 그 리소스가 그렇게 동작하는지 개념 노트로 돌아가 원리를 이해해야 변형 문제에도 대응할 수 있다.

- **실수 4**: "시험 당일 책상 위에 물이나 메모지 정도는 괜찮겠지"
  - 정정: 모니터/키보드/마우스 외의 모든 물건은 금지 대상이다. 사소한 규정 위반도 시험 중단 사유가 될 수 있다.

- **실수 5**: "네트워크나 웹캠은 시험 시작하고 나서 확인해도 된다"
  - 정정: System Check는 반드시 시험 전에 완료해야 하며, 시험 도중 장비 문제가 생기면 시간 손실로 직결된다.

## 빠른 복습

- Killer.sh는 CKA 등록 시 무료로 2회 제공되는 모의고사로, 실제 시험 환경과 매우 유사하지만 의도적으로 더 어렵게 출제된다.
- 1회차는 실전처럼 시간을 재고 혼자 풀어 현재 실력을 측정하고, 2회차는 취약 도메인 복습 후 검증 목적으로 활용한다.
- 오답은 도메인별(Architecture/Workloads/Networking/Storage/Troubleshooting)로 분류하고, 원인 유형(개념/명령어/시간/오독)까지 함께 기록해야 재발을 막을 수 있다.
- 시험 당일에는 신분증, 응시 공간 규정(책상 위 제한, 방 스캔), 프록터 시스템 사전 점검(카메라/마이크/네트워크), 시험 언어 설정을 미리 확인해야 한다.
- CKA는 정해진 커트라인 이상 획득해야 합격하며, 등록 시 보통 1회의 무료 재응시 기회가 포함된다.
